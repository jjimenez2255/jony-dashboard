# Shipped Inbox

Append a line every time we ship something. The Friday routine reads this file, integrates entries into the dashboard, and clears it.

## Format

```
- DATE · CLIENT · NAME · URL
```

Example:

```
- 2026-05-11 · Tend · Clark Hill Letter · tend-clark-hill.surge.sh
```
